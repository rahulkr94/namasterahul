# Rahul Kumar — Portfolio

A responsive Next.js portfolio for Rahul Kumar, built from the **Namaste Rahul** Stitch desktop and mobile designs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run typecheck
npm run build
```

The site is statically exported to `out/`.

## Content

Portfolio content is based on Rahul's résumé. Public links point to:

- [LinkedIn](https://www.linkedin.com/in/rahulmca94/)
- [GitHub](https://github.com/rahulkr94)

The contact form opens the visitor's configured email app; there is no backend or data collection.
